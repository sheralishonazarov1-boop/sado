# Sado

This project contains everything you need to run the app locally.

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Create a `.env.local` file and add your Gemini API key:
   `GEMINI_API_KEY=your_api_key_here`
3. Start the app:
   `npm run dev`

Open the local development URL shown in your terminal to use the app.
